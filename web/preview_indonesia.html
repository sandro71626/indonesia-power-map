Peta Ketenagalistrikan Indonesia

Combined preview yang menggabungkan dua region: JAMALI (Jawa-Madura-Bali, Step 1) dan Sumatra (Step 2). Halaman ini dipakai untuk menguji performa rendering multi-region sebelum region berikutnya (Kalimantan, Sulawesi, dst) ditambahkan.

Data di-load dari data_jamali.js dan data_sumatra.js — file yang sama yang dipakai preview per-region. Menambah region baru cukup tambah satu file data dan satu baris script.

Sumber: RUPTL PLN 2025–2034 (gardu induk & kapasitas), OpenStreetMap via Overpass API (pembangkit, transmisi, koordinat). Bukan alat operasi sistem tenaga; koordinat perlu verifikasi independen.
