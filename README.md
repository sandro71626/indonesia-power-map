# Indonesia Power Map — Legacy Repository

> **Status: Archived Development / Historical Reference**

This repository preserves the early development history of **Indonesia Power Map (IPM)**, first launched on 10 June 2026.

IPM has since evolved into a dedicated platform for exploring and analyzing Indonesia's electricity infrastructure. Its public datasets and website source code are now maintained separately.

## Current IPM Resources

| Resource | Link |
|---|---|
| Official Website | [indonesiapowermap.com](https://indonesiapowermap.com) |
| Open Data Repository | [IPM Model](https://github.com/sandro71626/ipm-model) |

The latest IPM website is hosted on Cloudflare Pages. Its development source code is maintained in a private repository, while the open datasets remain publicly accessible.

## About This Repository

This repository is retained as a historical record of IPM's initial development, documentation, and contributions.

The original application files have been removed from the active branch. Previous commits and release tags remain available for historical reference.

Thank you to everyone who has supported Indonesia Power Map since its initial launch.
